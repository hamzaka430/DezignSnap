Privacy Policy — Page Helper AI

Last updated: September 2026

What this extension does

Page Helper AI lets you capture a screenshot of the currently visible part of a webpage and send it, together with an instruction you configure, to OpenAI's API or Google's Gemini API (whichever you select, using your own API key for that provider) to get an answer.

What data we collect

We (the extension developer) do not operate any server and do not collect, receive, or store any of your data ourselves. All data handled by this extension stays either on your device or is sent directly from your browser to OpenAI or Google Gemini.

What is stored locally on your device

  • Your OpenAI and/or Gemini API key(s) (used only to authenticate requests to the selected provider's API from your browser).
  • Which provider (OpenAI or Gemini) is currently active.
  • Your saved instruction presets.
  • A session history of your Q&A exchanges (instruction, AI answer, page title/URL, and a compressed screenshot thumbnail), used only to generate the PDF export you request and to show you a local history. This can be cleared at any time from the extension's Settings page.

This data is stored using the browser's built-in extension storage and is not synced to any external service by this extension.

What is sent to third parties

When you use the "Solve with AI" feature, a screenshot of your currently visible tab and your instruction text are sent directly from your browser to whichever provider you have selected — OpenAI's API (api.openai.com) or Google's Gemini API (generativelanguage.googleapis.com) — using your own API key for that provider, so it can generate a response. This request is authenticated with your key and billed to your account with that provider. Please refer to OpenAI's Privacy Policy or Google's Privacy Policy for how each provider handles data sent to its API.

We do not intercept, log, or have access to this data at any point.

Permissions this extension requests, and why

  • storage — to save your API key, instruction presets, and session history locally.
  • activeTab — to allow the popup to capture a screenshot of the tab you're currently viewing.
  • unlimitedStorage — to allow storing screenshot thumbnails in your local session history without hitting the default storage quota.
  • host_permissions (<all_urls>) — required so the on-page "Solve with AI" / "End Session" buttons can be shown on any website you visit, and so a screenshot can be captured when you click that on-page button (this action is not initiated via the browser toolbar, so the narrower activeTab permission alone is not sufficient for it).
  • host_permissions (api.openai.com, generativelanguage.googleapis.com) — required to send your requests directly to OpenAI's and/or Google Gemini's API, whichever you choose to use.

Your controls

You can clear your session history at any time from the Settings page. You can remove your API key at any time by clearing the field in Settings. Uninstalling the extension removes all locally stored data.

Children's privacy

This extension is not directed at children and does not knowingly collect data from children.

Changes to this policy

If this policy changes, the "Last updated" date above will be revised.
