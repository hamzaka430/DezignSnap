Quick Setup in 4 Steps

1

Get an API Key or Use Local AI

Choose your preferred provider: Groq (Ultra-Fast) • Gemini (Free) • OpenAI • OpenRouter • or run Ollama locally for 100% free offline usage.

2

Pin & Configure

1. Pin the extension to your Chrome toolbar.
2. Click the icon, open Settings, and save your API key.

3

Enable Local File Access (Optional)

To let the AI analyze local PDFs or images on your machine: Go to chrome://extensions → Click Details on this extension → Toggle "Allow access to file URLs" to ON.

4

Start Snipping!

Press Alt + S or click Snip Area on any page, drag a rectangle over anything you want explained, and get instant answers!

Local AI Setup (Ollama 100% Private)

To run local vision models without sending any screenshots over the internet, configure Ollama to accept browser requests by starting it with origins enabled:

set OLLAMA_ORIGINS=* && ollama serve

Then pull a vision model in your terminal: ollama pull llama3.2-vision, select Ollama in settings, and you are ready!
