## Usage Notes
- SVG files are vector — scale to any size without quality loss
- Convert to PNG using Figma, Inkscape, or Adobe Illustrator
- Chrome Web Store requires PNG icons (16, 32, 48, 128px)
- Use wordmark for marketing; pictorial mark for app icon; lettermark for favicon
