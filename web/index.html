Which Web Vital metric measures visual stability during page load?

Verified Correct Answer: Option B (CLS - Cumulative Layout Shift)

  • Why B is correct: CLS specifically measures unexpected layout shifts that occur as elements load asynchronously, quantifying visual stability.
  • Why A is incorrect: LCP measures perceived loading speed (when the primary page content finishes rendering).
  • Why C is incorrect: INP measures page responsiveness to user interactions (clicks, taps, keystrokes).
  • Why D is incorrect: TTFB measures server response time for the initial document payload.

Frequently Asked Questions

How is DezignSnap licensed and priced? ▾

DezignSnap is available exclusively through the official Chrome Web Store. The core extension operates on a Bring-Your-Own-Key (BYOK) model, enabling you to use free-tier API keys from Groq or Google AI Studio (Gemini 2.5 Flash), or run 100% free and offline using local Ollama. As our user community grows, optional premium plans and hosted AI credits will be introduced for users who prefer ready-to-use access without managing their own API keys.

How does the side toggle dock work? ▾

When you click the side toggle button on the floating toolbar, DezignSnap docks flush against the edge of your screen as a sleek side toggle tab. Clicking or hovering over it smoothly reveals and expands the toolbar. If you leave the toolbar open and don't interact with it for 1 minute, it automatically auto-collapses to keep your screen clutter-free.

Does DezignSnap store or see my screenshots? ▾

Never. There are zero middleman servers. When you snip an area, your browser makes a direct API call to your chosen provider (Groq, Google Gemini, OpenAI, or local Ollama). We collect zero personal data, run zero telemetry, and maintain zero tracking cookies.

Can I analyze local PDF files or images from my hard drive? ▾

Yes. Go to chrome://extensions, click Details on DezignSnap, and switch the "Allow access to file URLs" toggle to ON. You can then open any local PDF or image file directly in Chrome and snip it with Alt+S.

How do I configure local Ollama for 100% offline usage? ▾

Launch Ollama with origins enabled so Chrome extensions can communicate with it: set OLLAMA_ORIGINS=* && ollama serve. Then pull a vision model such as ollama pull llama3.2-vision, select Ollama in DezignSnap settings, and you have complete offline visual intelligence!
